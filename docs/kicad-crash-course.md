# KiCad 速成：只学做这个作业需要的部分

目标不是学会画板，是搞清楚**你的 Agent 到底要吐出什么**。

---

## 一、四个必须分清的概念

| 概念 | 是什么 | 类比 |
|---|---|---|
| **符号 Symbol** | 原理图上的图形，定义"这个器件有哪些引脚、引脚叫什么" | 电路图上的一个方框 |
| **封装 Footprint** | PCB 上的焊盘形状和尺寸，定义"这个器件焊在板上长什么样" | 器件的实际尺寸 |
| **网表 Netlist** | 谁和谁连在一起，`(U1, pin7) — (R1, pin1) — (C1, pin1)` | 接线清单 |
| **工程 Project** | `.kicad_pro` 把上面这些串起来的总入口 | 一个文件夹的封面 |

**关键认知**：符号和封装是两套东西，通过"符号的 Footprint 字段"关联。你的 Agent 如果只生成了符号名却对不上库里真实存在的符号，原理图打开就是一堆红叉。

同一个器件：
- 符号叫 `MCU_Microchip_ATmega:ATmega328P-PU`（库名:符号名）
- 封装叫 `Package_DIP:DIP-28_W7.62mm`

## 二、文件格式与数据流

```
一句话需求
   ↓  LLM
BOM（位号 + 型号 + 数量 + 封装）
   ↓  LLM
连接关系 JSON（net → 引脚列表）      ← W3–W4 的产出
   ↓  脚本
xxx.kicad_sch（原理图，S-expression 文本）  ← W5–W6 的产出
   ↓  KiCad 内部
xxx.kicad_pcb（PCB 布局布线）
   ↓
Gerber（给板厂的文件）
```

必须认识的文件后缀：

- `.kicad_pro` — 工程配置
- `.kicad_sch` — 原理图，**纯文本 S-expression**，可以直接用 Python 生成
- `.kicad_pcb` — PCB，`pcbnew` 模块管这个
- `.kicad_sym` — 符号库
- `.kicad_mod` — 封装库
- `.net` — 网表（KiCad 可以导出，用于跟外部工具交换）

## 三、五个坑（先看，能省你一整天）

### 坑 1：`pcbnew` 只有 KiCad 自带的 Python 能 import

你在自己的 venv 里 `pip install pcbnew` 是装不上的。KiCad 8 自带一个 Python（通常 3.11），`pcbnew` 只在那个解释器里存在。

`scripts/hello_kicad.py` 已经处理了：检测不到就自动用 `KiCad\8.0\bin\python.exe` 重新执行自己。

### 坑 2：KiCad 8 没有官方 eeschema（原理图）Python API

`pcbnew` 只管 PCB。**画原理图这件事 KiCad 8 没给你现成的 Python 接口**。可行的三条路：

1. **直接生成 `.kicad_sch` 文本** —— 最常见，也最符合"Agent 生成文件"的思路
2. **用 `kicad-skip` 等第三方库** —— 解析/修改已有 `.kicad_sch`
3. **用 `kicad-cli` 做导出** —— 只能导出（PDF/SVG/网表），不能创建

**先把这条和课程模板的实现方式对齐**，如果模板用的是路径 1，你就别去折腾 API 了。

### 坑 3：`.kicad_sch` 里"连接"是靠坐标的，不是靠名字

这是最容易低估的地方。S-expression 里：

- 元件的引脚位置由**元件坐标 + 引脚相对偏移**算出来
- 两根线"连上了"是因为**线段端点坐标完全相等**
- 所以生成原理图时，**布局坐标必须自己算**，得保证引脚落点和导线端点严丝合缝

理解这一点，你就明白为什么 W5–W6 需要两周。

### 坑 4：符号库里没有的器件，原理图一定打不开

LLM 很容易编一个"看起来很像"的型号。必须做校验：生成的每个符号名都要在 `data/` 的器件库里查得到，查不到就让 LLM 重生成——这就是**反馈闭环**最实际的用法。

### 坑 5：中文路径

KiCad 本身能读中文路径，但 Python 脚本里拼路径、写文件时，注意统一用 `pathlib.Path` 和 UTF-8，别混着用 `os.path` 字符串拼接。

## 四、Arduino 最小系统板：你的第一个目标

"最小系统"= 让单片机跑起来所必需的最少外围电路。ATmega328P 版本就五块：

| 电路 | 元件 | 为什么必须有 |
|---|---|---|
| **电源** | 5V 输入 + 100nF 去耦 ×2 + 10µF 滤波 | 芯片要供电，去耦电容抑制高频噪声 |
| **复位** | 10kΩ 上拉到 VCC + 轻触开关到 GND | 上电复位、手动重启 |
| **时钟** | 16MHz 晶振 + 22pF 负载电容 ×2 | 提供时钟，没它芯片不跑 |
| **下载** | 2×3 ISP 排针（MISO/MOSI/SCK/RESET/VCC/GND） | 烧程序进来 |
| **指示** | LED + 330Ω 限流电阻 | 确认上电了 |

参考清单见 `data/arduino_min_system_bom.csv`。

**为什么选它**：电路极经典、网上一堆参考、示例库里大概率有现成的——正好拿来当"标准答案"对照你的 Agent 输出对不对。

## 五、动手 20 分钟

1. KiCad 里打开示例工程，双击一个电容，看 **Symbol** 和 **Footprint** 两个字段的值
2. 菜单「工具 → 生成网表」，导出一份 `.net`，用记事本打开
3. 找到其中一行 `(net (code "1") (name "GND") ...)`，看它怎么列出所有连到 GND 的引脚
4. 想一下：如果让你写代码生成这个结构，你需要哪些数据？

做到第 4 步，你对 W3 要干什么就有画面了。
