## 二、逐条说明

### ② 山大 AI 助手 / 智能体平台

- **AI 助手**：`https://service.sdu.edu.cn` → 登录后页面右侧「AI 试验场」→「AI 助手」。
  手机端搜「山大智能助手」App。
  平台搭载满血版 DeepSeek、Qwen 等模型。
- **智能体平台**：`https://agentlab.sdu.edu.cn/product`（或 `aihub.sdu.edu.cn`），
  基于 HiAgent，支持 Agent / 插件 / 工作流 / 知识库 / 数据库，可低代码搭智能体。

**对本作业的价值**：如果平台开放 API 调用（部分部署支持给已发布智能体生成 API），
可以直接当 LLM 后端用；否则可以用它做 Prompt 调试，把调好的 Prompt 搬到自己的代码里。

**要确认的事**：登录后在「个人空间」看有没有「API 密钥 / 应用调用凭证」之类的入口。

### ③ 山大云

- 地址：`https://yun.sdu.edu.cn`，统一认证直接登录
- 提供：弹性云服务器（Windows / CentOS / Ubuntu 镜像，立申立用）、云电脑（含 vCPU/GPU/内存配置）、
  容器支撑平台、大数据支撑平台
- 规模：约 5760 逻辑核、62TB 内存、5120TB 存储（全校共享，属"普惠区"，资源尽力而为）

**对本作业的价值**：拿一台 GPU 云主机，用 vLLM 部署 Qwen 之类开源模型，
就能得到**完全自主的 OpenAI 兼容接口**，不依赖外部密钥。

**代价**：要会 Linux、会装环境、要调通端口映射。以你现在的进度，这是 3 小时起步的活。

### ④ 高性能计算云平台

- 地址：`http://cloud.sdu.edu.cn`，浏览器直接访问（推荐 Chrome / Firefox）
- 定位：中等规模高性能计算，容器技术，近 20 个计算应用模板（含深度学习）
- 规模：算力 >300 TFLOPS，存储 >1PB
- 联系电话：0531-88391261

**注意**：这是**校级公共技术平台**，面向科研。账号申请一般要经过所在单位审核，
本科生单独申请大概率需要指导教师背书。作业场景不建议走这条。

### 附：威海校区超级计算中心（如你在威海）

- 主页：`http://hpc.wh.sdu.edu.cn`
- 架构：CPU + GPU + MIC 异构，856 个 CPU 核，2 台 GPU 节点
- 申请：登录信息化门户 → 服务大厅 → 搜索「超级计算中心」→ 账号申请（威海）
- 流程：申请表 → 单位领导审核 → 预缴费 → 下发账号
- 咨询：0631-5686907（程老师、杨老师、车老师）

**注意**：需要**预缴机时费**，且要熟悉 Linux 与作业调度（TORQUE）。作业用不上。

## 三、怎么查自己有哪些权限

```
1. 打开 https://service.sdu.edu.cn ，统一认证登录
2. 进「服务大厅」
3. 搜索这几个关键词，逐个看申请条件和角色限制：
   算力 / 超算 / 虚拟机 / 云主机 / 智创 / 智能体
4. 每个条目都会写明「服务对象：本科生 / 研究生 / 教职工」
```

**关键**：很多条目只对研究生和教职工开放。你是本科生的话，先看清楚"服务角色"那一栏。

## 四、结论

对这个作业而言：

- **别绕远路**。课程 PPT 明确承诺了「统一密钥与额度」，这是设计好的路径，问助教最快。
- 学校资源里，**山大 AI 助手/智能体平台**最值得先试（零成本、零配置）。
- **山大云 GPU 自部署**是自己搭一套的硬核方案，能力上完全够，但时间成本对"赶作业"不划算。
- 超算中心不适合：要缴费、要 Linux、要审核。
