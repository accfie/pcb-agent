## 第 1 节：GitHub，从注册到第一次提交（第 1 天，约 2 小时）

### 1.1 先弄清楚 Git 和 GitHub 不是一回事

- **Git** = 装在你电脑上的存档工具（你已经装好了，版本 2.55）
- **GitHub** = 网上的仓库托管网站，负责把存档同步上去

**为什么必须用**：PPT 第 8 页写了，过程分 10 分看的就是 commit 记录，仓库就是你的"成长日记"。每周没有 commit，那 10 分就没了。

### 1.2 注册账号

打开 https://github.com → Sign up → 填邮箱、密码、用户名。

**如果访问很慢或打不开**：换成 **Gitee（码云）** https://gitee.com 。PPT 第 8 页明确写了 "GitHub / Gitee" 都行，后面所有命令完全一样，只是网址不同。国内访问 Gitee 顺畅得多，新手用它能少踩一半坑。

### 1.3 在网站上建一个仓库

1. 右上角 `+` → **New repository**
2. Repository name 填：`pcb-agent`
3. 选 **Private**（作业别公开）
4. **下面三个勾选框全部不要勾**（Add README / .gitignore / license）——你本地已经有这些文件了，勾了会冲突
5. 点 **Create repository**

建完页面会显示一个地址，形如：

```
https://github.com/你的用户名/pcb-agent.git
```

**把这个地址复制下来，等下要用。**

### 1.4 配置本地身份（一次性）

打开 Git Bash 或 PowerShell：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱"
```

这两行决定了每个 commit 上显示的作者是谁。不配的话 commit 会直接失败。

### 1.5 把本地项目和远程仓库连起来

```bash
cd "D:\study\人工智能基础\电路板设计\pcb-agent"
git remote add origin https://github.com/你的用户名/pcb-agent.git
git branch -M main
git push -u origin main
```

`git remote add origin` 的意思是："以后我说 origin，指的就是那个网址"。
`git branch -M main` 把主分支改名叫 main（GitHub 的默认叫法）。

### 1.6 推送时会要密码——GitHub 密码不行，要用 Token

这是新手第一个大坑。**GitHub 从 2021 年起不再接受账号密码**，必须用 Personal Access Token。

生成方法：

1. GitHub 右上角头像 → **Settings**
2. 左侧拉到最底 → **Developer settings**
3. **Personal access tokens** → **Tokens (classic)**
4. 右上 **Generate new token** → **Generate new token (classic)**
5. Note 随便写：`pcb-agent`
6. Expiration 选 90 days
7. 下面勾选 **repo**（这一项就够）
8. 拉到底 **Generate token**
9. 页面显示一串 `ghp_xxxxxxxxxxxx`，**立刻复制存到记事本**——离开页面就再也看不到了

推送时提示 `Username:` 输你的 GitHub 用户名，`Password:` **粘贴那串 token**（粘贴时屏幕不显示任何字符，是正常的，粘完直接回车）。

> 用 Gitee 的话简单得多：直接用账号密码，不需要 token。

### 1.7 以后每天只有四个动作

```bash
git status                    # 看改了哪些文件
git add .                     # 把改动加入暂存区
git commit -m "W1: 环境搭建"    # 存一个本地快照
git push                      # 上传到网站
```

**关键理解**：`commit` 是存在你自己电脑上的，`push` 才是传到网站。**只 commit 不 push，助教看不到，等于没交。**

### 1.8 新手三个高频错误

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `fatal: not a git repository` | 没在项目目录里执行 | 先 `cd "D:\study\人工智能基础\电路板设计\pcb-agent"` |
| `rejected - non-fast-forward` | 网站上改过东西，本地不知道 | `git pull` 再 `push` |
| 提交上去发现带了密钥 | `.env` 没被忽略 | 本项目 `.gitignore` 已经防住了，别手动 `git add .env` |

## 第 2 节：电路常识急救包（第 2 天，约 1 小时）

只要七个概念，每个都直接对应作业里的东西。

### 概念 1：GND 和 VCC

- **VCC**（也写作 +5V、VDD）= 电源正极，电压高的那头
- **GND** = 地，电压定义为 0，是全电路共同的参照点

打个比方：GND 是地面的海拔 0 米，VCC 是海拔 5 米。所有电压都是"相对 GND"说的。

**作业里对应**：你生成的网表里，一定有一个叫 `VCC` 的网络和一个叫 `GND` 的网络，它们连着最多引脚。

### 概念 2：电流必须走成一个圈（回路）

电流从 VCC 出发，经过元件，回到 GND，再通过电源回到 VCC。**断在任何一处，整个电路都不工作。**

这就是为什么 LED 电路必须有两条线：一条从 +5V 到 LED，一条从 LED 到 GND。

**作业里对应**：如果你的网表里某个网络只有 1 个引脚，那就是"断头路"——`check_netlist.py` 会给你警告。

### 概念 3：欧姆定律 U = I × R

记住一个变形就够用：**R = U ÷ I**

**LED 限流电阻怎么算**（这是最小系统板里唯一要算的东西）：

- 电源 5V，LED 工作电压约 2V，所以电阻要承担 `5 - 2 = 3V`
- LED 正常电流取 10mA = 0.01A
- 电阻 = 3 ÷ 0.01 = **300Ω** → 取标准值 **330Ω**

这就是 BOM 里那个 R2 = 330Ω 的来历。**如果算错会怎样**：电阻太小 → LED 烧掉；太大 → LED 不亮。这是最典型的"设计错误"，正好可以写进报告的失败案例分析。

### 概念 4：电容是干什么的

电容不消耗电，它"存一下再放一下"。作业里只有两种用法：

| 用法 | 容值 | 干什么 | 放在哪 |
|---|---|---|---|
| **去耦** | 100nF | 芯片瞬间要电流时先顶上，滤掉高频噪声 | 紧挨芯片的电源脚 |
| **晶振负载** | 22pF | 帮晶振起振、稳定频率 | 晶振两端各一个，另一头接地 |

**作业里对应**：BOM 里的 C3、C4 是去耦，C1、C2 是晶振负载。为什么必须有两个 100nF 而不是一个——因为 ATmega328P 有两个电源脚（VCC 和 AVCC），每个脚旁边都要配一个。

### 概念 5：二极管有方向

二极管只让电流单向通过。LED 也一样：**阳极（A）→ 阴极（K）**，接反了不亮。

**作业里对应**：网表里 D1 的 `pin 1` 是 K，`pin 2` 是 A。你如果让 LLM 随便连，很可能接反。**这就是"引脚级"三个字的含义**——光说"D1 接 VCC"不够，得说"D1 的 pin 2 接 VCC"。

### 概念 6：引脚号 vs 引脚名

一个芯片同一个引脚有两个标识：

- **引脚号**：1、2、3…28，物理上是第几根脚
- **引脚名**：VCC、GND、RESET、PB6/XTAL1，功能叫什么

比如 ATmega328P：**引脚 7 号叫 VCC，引脚 8 号叫 GND，引脚 1 号叫 RESET**。

**作业里对应**：网表必须用**引脚号**，因为 KiCad 内部就是按号连的。用名字会连不上。

### 概念 7：网络（net）与网表（netlist）

- **网络**：一组"连在一起"的引脚。比如所有接到 GND 的引脚，共同构成 GND 这个网络。
- **网表**：把"有哪些网络、每个网络包含哪些引脚"写成一份清单。

**这就是你 W3–W4 要产出的东西**，格式在 `data/sample_netlist.json` 里，打开看一眼就懂了：

```json
{
  "name": "RESET",
  "nodes": [
    { "ref": "U1",  "pin": "1" },   // ATmega328P 的复位脚
    { "ref": "R1",  "pin": "2" },   // 10k 上拉电阻
    { "ref": "SW1", "pin": "1" },   // 复位按钮
    { "ref": "J1",  "pin": "5" }    // ISP 下载口的 RESET
  ]
}
```

翻译成人话："U1 的 1 号脚、R1 的 2 号脚、SW1 的 1 号脚、J1 的 5 号脚，全部连在一起，这个网络叫 RESET。"

**看懂这一段，你就看懂了整个作业的核心。**

### 顺带：最小系统板为什么是这五块电路

| 电路 | 少了会怎样 |
|---|---|
| 电源 + 去耦 | 芯片不工作 |
| 复位（10k 上拉 + 按钮） | 上电可能起不来，也没法手动重启 |
| 晶振（16MHz + 2×22pF） | 芯片没有时钟，完全不动 |
| ISP 下载口 | 程序烧不进去 |
| LED 指示 | 不知道到底通没通电 |

记这五条，答辩被问"为什么这么连"就答得上来。详细版在 `docs/kicad-crash-course.md`。

## 第 3 节：KiCad 从零（第 3 天，约 2 小时）

### 3.1 安装

**版本必须对：课程用 KiCad 8，官网首页现在给的是最新版（10.x），不要直接下首页那个。**

为什么较真：KiCad 不提供"另存为旧版本"。用 10 存出来的 `.kicad_sch`，助教用 8 打不开，
等于交了打不开的原理图。这类硬伤不扣分是运气。

下载 KiCad **8.0.8**（国内推荐阿里云镜像，比官网快）：

```
https://mirrors.aliyun.com/kicad/windows/stable/kicad-8.0.8-x86_64.exe
```

备用（GitHub 官方源）：

```
https://github.com/KiCad/kicad-source-mirror/releases/download/8.0.8/kicad-8.0.8-x86_64.exe
```

安装步骤：

1. 双击安装包
2. 组件里把 **Symbols / Footprints / 3D Models** 三组库都勾上（不装符号库，画图时一个元件都放不出来）
   - Python 支持是内置的，Windows 安装包没有单独的勾选项，不用找
3. 路径保持默认 `C:\Program Files\KiCad\8.0`
4. 首次启动会问要不要导入旧配置，选"否/跳过"
5. 装完跑 `python scripts/env_check.py`，确认版本检查显示 `[ OK ] KiCad 版本匹配`

装完在开始菜单里能看到 **KiCad 8.0** 这一组程序。

### 3.2 你只需要认识两个窗口

| 窗口 | 中文名 | 干什么 | 你要不要用 |
|---|---|---|---|
| **Schematic Editor** | 原理图编辑器 | 画电路连接关系 | ✅ 主要用这个 |
| **PCB Editor** | PCB 编辑器 | 画板子、走线 | 进阶才用 |
| Symbol Editor | 符号编辑器 | 改元件图形 | ❌ 别碰 |
| Footprint Editor | 封装编辑器 | 改焊盘 | ❌ 别碰 |

**原理图 = 电路长什么样（谁连谁）；PCB = 板子长什么样（东西摆哪、线怎么走）。** 先有原理图，才能有 PCB。

### 3.3 三分钟认识界面

打开 Schematic Editor 后，左边竖着一排图标，你只需要最上面几个：

- **放大镜**：放大缩小
- **运放符号（三角形）**：放置元件
- **绿色斜线**：画导线
- **GND 符号**：放置电源/地

### 3.4 必须记住的六个快捷键

| 键 | 作用 |
|---|---|
| **A** | 添加元件（Add Symbol） |
| **W** | 画导线（Wire） |
| **R** | 旋转元件（放之前按，可以换方向） |
| **G** | 抓住元件拖动 |
| **E** | 编辑属性（改阻值、改封装） |
| **Delete** | 删除 |

还有 **P** 是放置电源符号（+5V / GND）。如果按了没反应，就用菜单「放置 → 电源符号」。

### 3.5 手把手：画一个 LED 电路（这是你今天最重要的 20 分钟）

不要一上来就画最小系统板，先画一个只有三个元件的东西。**走完这一遍，你就理解"原理图"是什么了。**

**第 1 步：新建工程**

`文件 → 新建工程` → 存到 `D:\study\人工智能基础\电路板设计\my_first_board\`
（KiCad 会自己建同名文件夹，里面出现 `.kicad_pro` 和 `.kicad_sch`）

**第 2 步：放一个电阻**

1. 按 **A**
2. 弹出的库里搜 `R`
3. 选 `Device:R`，点 **OK**
4. 在画布上点一下放下
5. 按 **R** 可以旋转

**第 3 步：改它的阻值**

鼠标悬停在电阻上按 **E**（或双击）→ 把 `Value` 从 `R` 改成 `330` → OK

**第 4 步：再放一个 LED**

按 **A** → 搜 `LED` → 选 `Device:LED` → 放下

> 注意 LED 有方向！引脚旁的 `A` 是阳极，`K` 是阴极。等下连线时，**A 要朝 +5V 那边**。

**第 5 步：放电源和地**

1. 按 **P** → 选 `+5V`（如果没有，选 `VCC`）→ 放下
2. 再按 **P** → 选 `GND` → 放下

这两个符号长得不起眼，但意义重大：**所有叫 +5V 的点，不管画在哪，KiCad 都认为是同一个网络。** 这就是"网络"概念在软件里的体现。

**第 6 步：连线**

1. 按 **W**
2. 从 +5V 符号的引脚，拉到电阻的一端，点一下确定
3. 继续：电阻另一端 → LED 的 A 脚
4. 再：LED 的 K 脚 → GND 符号
5. 按 **Esc** 退出连线模式

**第 7 步：检查对不对**

菜单 `检查 → 电气规则检查（ERC）`。第一次画一定会冒出几条警告，不用全懂，只要**没有"未连接的引脚"**就说明线连上了。

**第 8 步：看一眼网表（重点）**

菜单 `工具 → 生成网表` → 选 `KiCad` 格式 → 导出。
用记事本打开那个 `.net` 文件，找到类似这样的段落：

```
(net (code "1") (name "GND")
  (node (ref "D1") (pin "1"))
  ...
)
```

**这就是你在 1.7 节看到的 JSON 的另一种写法。** 看到这一刻，你就明白 W5 要干什么了——你的 Agent 就是要生成这种东西。

**第 9 步：保存**

`Ctrl+S`。这一步别忘，KiCad 不会自动存。

### 3.6 然后打开模板/示例，对照着看

自己从零画最小系统板是浪费时间——**23 个元件、几十条线，你画到半夜也画不完，而且没必要**。

正确做法：

1. 打开课程模板工程，或 KiCad 自带示例（`帮助 → 打开示例工程`）
2. **双击任意一个元件**，看属性窗口里的三个字段：
   - `Reference`：位号，就是 U1、R1、C1
   - `Value`：值，就是 330、100nF、ATmega328P-PU
   - `Footprint`：封装，长这样 `Resistor_SMD:R_0603_1608Metric`
3. 在画布上点一条线，看它高亮了多少个引脚——**高亮的这些，就是同一个网络的所有成员**

**看懂这一步，你的 KiCad 学习就结束了。** 后面都是体力活，不是认知门槛。

## 第 5 节：卡住的时候怎么办

### 自查顺序（按这个顺序，别跳）

1. **完整读报错的最后一行**。Python 的报错真正的信息在最后一行，前面的都是调用栈。
2. **看路径对不对**。80% 的"找不到文件"都是路径错或当前目录错。
3. **确认在虚拟环境里**。命令行前面有没有 `(.venv)`。
4. **原样复制报错去搜**。搜索时去掉你自己的文件名和路径，只留报错关键词。

### 问我（或任何 AI）时的正确姿势

不要只发一句"报错了"。给这三样：

```
1. 我想做什么：（比如：运行环境自检）
2. 我执行了什么：（完整命令）
3. 完整报错：（从第一行到最后一行，别截断）
```

只给第 3 样也能回答，但会慢很多。

### 一个反直觉但重要的建议

**一次只改一个东西。** 新手最常见的死法：同时改了三处，结果好了不知道哪处起了作用，坏了也不知道是哪处搞坏的。

## 第 6 节：术语中英对照（KiCad 是英文界面，必备）

| 英文 | 中文 | 一句话 |
|---|---|---|
| Schematic | 原理图 | 谁连谁 |
| PCB | 印制电路板 | 东西摆哪、线怎么走 |
| Symbol | 符号 | 原理图上的图形 |
| Footprint | 封装 | 焊盘的实际形状尺寸 |
| Reference / Ref | 位号 | U1、R1、C1 |
| Net | 网络 | 连在一起的一组引脚 |
| Netlist | 网表 | 网络清单 |
| Pin | 引脚 | 元件上的脚 |
| Pad | 焊盘 | 板上焊元件的铜皮 |
| Trace | 走线 | 板上连通的铜线 |
| Via | 过孔 | 换层用的洞 |
| BOM | 物料清单 | 买什么、买几个 |
| ERC | 电气规则检查 | 查原理图有没有低级错 |
| DRC | 设计规则检查 | 查 PCB 有没有画错 |
| Library | 库 | 元件/封装的集合 |
